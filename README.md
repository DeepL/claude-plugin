# DeepL plugin for Claude

The official DeepL plugin connects Claude to DeepL for translation, writing improvement, glossary access, and document translation.

## Install

Add this repository as a Claude Code marketplace, then install the DeepL plugin:

```sh
claude plugin marketplace add DeepL/claude-plugin
claude plugin install deepl@deepl
```

Claude opens the DeepL sign-in flow when the plugin first needs access. An eligible DeepL subscription is required.

## Releases

The plugin files in this repository are generated and published from the private `deepl-mcp` source repository. Do not edit generated plugin files directly.
